How Tox21 Prediction Works

1 · What is Tox21?

The Tox21 programme screened ~10,000 environmental chemicals and drugs across 12 toxicological assays covering nuclear receptor signalling and cellular stress response pathways. Each assay labels a compound as active (toxic signal detected) or inactive.

2 · SMILES notation

A SMILES string (Simplified Molecular-Input Line-Entry System) encodes a molecule's structure as a short text string. Atoms are written as their element symbols; bonds, branches, and rings are represented by punctuation. For example aspirin is CC(=O)Oc1ccccc1C(=O)O.

3 · Morgan fingerprints

Each SMILES is parsed by RDKit and converted to a 2048-bit circular (Morgan) fingerprint at radius 2. Each bit records whether a particular atomic neighbourhood pattern is present in the molecule, giving a fixed-length binary vector that neural networks can process.

4 · Neural network

A fully-connected network with architecture 2048 → 512 → 128 → 32 → 1 is trained per assay. Training uses the Adam optimiser (lr=0.001), dropout (p=0.5) for regularisation, and weight decay (λ=1×10⁻⁴). The single output neuron uses a sigmoid activation; a value ≥ 0.5 is classified as active.

5 · Inference

At prediction time dropout is disabled (weights are used as-is). The fingerprint is fed forward through the trained weights and the sigmoid output is thresholded at 0.5 to give an Active / Inactive call for each assay that has a trained model.
